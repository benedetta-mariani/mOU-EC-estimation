# EC estimation

Open `EC_pipeline_precision.ipynb` to estimate mOU connectivity and select tau at the minimum correlation with a precision-based reference, within the convergent range. The notebook includes diagnostics, EC comparisons across tau, and a reload section.

Set the subject and input path, install dependencies from `requirements.txt`, and run the sections in order. Local pyMOU source and its license are included. Only selected matrices and compact diagnostics are saved; results are excluded from Git.
