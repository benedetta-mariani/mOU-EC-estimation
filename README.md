# mOU EC estimation

Code for estimating effective connectivity with a multivariate Ornstein–Uhlenbeck model and reproducing the manuscript figures.

- [EC estimation pipeline](ec_estimation/): a simple notebook with tau selection based on EC–Q1 correlation, including local pyMOU source and its license.
- [Figure notebooks](figures/): analyses and plots used in the manuscript.

Input data are not included. Update the data paths before running the notebooks; HCP data are available through the Human Connectome Project under its access terms.
